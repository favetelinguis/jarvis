# Diátaxis forms of the board

The form of each page and section. The board reads them from one place
(the Diátaxis module of the web layer); keep this file in step with it.

## Plain language

- One idea per sentence; at most 20 words.
- Active voice: say who does what ("The agent answers", not "It is answered").
- Use the reader's words; define a term the first time, or link to the Guide.
- Buttons name the result: "Send comment", "Save colors", "Install".
- Messages say what happened and what to do next.
